# P1 Utopian Sky
## About
This is the script for P1 Utopian Sky. It provides guidance on the following two mechanics during Utopian Sky.

Navigation Support:

- Prismatic Deception
    - 8 direction spread
    - avoid blasting zone
    - stack (red) or spread (blue) position
- Halo of Flame (Light Circle, 光輪)
    - Group Resolve by Debuff
    - Final Group Stack

Cyclonic Break (side-to-side dashing) is not covered in this script. Please use [P1 Cyclonic Break](https://raw.githubusercontent.com/PunishXIV/Splatoon/refs/heads/main/SplatoonScripts/Duties/Dawntrail/The%20Futures%20Rewritten/P1%20Cyclonic%20Break.cs).

## Configuration
![](../../../../assets/dawntrail/fru_p1_utopiansky_setting.png)

You need to configure both Prismatic Deception and Halo of Flame (Light Circle).

### Prismatic Deception Settings > Spread direction
Set the directions for the 8-way spread.

### Prismatic Deception Settings > Avoid Blasting Zone directions
Set the safe zones for the invisible straight-line ranges.

### Prismatic Deception Settings > Thunder spread Position
Set the positions within the group for the “Thunder” spread.

### Light Circle Settings > North group priority
Set the 4 members who will gather on the north side.

### Light Circle Settings > South group priority
Set the 4 members who will gather on the south side.

### North Adjuster
Set 1 coordinator from among the 4 members in the north group.

### South Adjuster
Set 1 coordinator from among the 4 members in the south group.
