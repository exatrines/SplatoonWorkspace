# P3 Transition
## About
This script provides full guidance for P3 Transition.

- Spread direction by group
- Avoiding the Wave Pulse (donut) AOE

The pulse (donut wave) AOE is not displayed by this script. Please import your preferred layout for it.

### Priority settings

### Group direction settings
You can configure which group handles the mechanic in which direction.
