# P5 Dynamis Sigma Relative Tower Finder
## About
Resolve the tower you should enter based on the relative positions of your Wave Cannon's Spread point and the tower.

Note: It does **not** navigate PlayStation alignment or Wave Cannon spread. Use it together with the official [Dynamis Sigma](https://github.com/PunishXIV/Splatoon/blob/main/Presets/Endwalker/Duties/Ultimate%20-%20The%20Omega%20Protocol/Phase%205%20-%20Dynamis%20Omega%20-%202.%20Sigma.md) script.
