## Configuration

![](../../../../assets/endwalker/p5_dynamis_omega_hello_world_setting.png)

**Spread1** と **Spread2** に、それぞれマーカーと担当を指定してください。

### Resolve BaitNear
ニア誘導をマーカーではなく、ロールに割り当てられていない残り 2 名で決定します。チェックすると BaitNear1・2 が非表示になり、誘導位置の両方にテザーが表示されます。

### Resolve BaitTether
オメガ紐の誘導をマーカーではなく、デュナミスが 3 の 2 名で決定します。チェックすると BaitTether1・2 が非表示になり、誘導位置の両方にテザーが表示されます。
