# P5 Dynamis Sigma Relative Tower Finder
## About
コード:＊＊＊ミ＊【シグマ】における「塔マクロ押さない式」のスクリプトです。波動砲の散開位置を基準に、どの塔へ入るべきかガイドします。

注意: プレステ整列および波動砲の散開はこのスクリプトではガイドしません。公式スクリプトの [Dynamis Sigma](https://github.com/PunishXIV/Splatoon/blob/main/Presets/Endwalker/Duties/Ultimate%20-%20The%20Omega%20Protocol/Phase%205%20-%20Dynamis%20Omega%20-%202.%20Sigma.md) と併用することを推奨します。
